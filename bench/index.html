Hosted runners can change between runs. Start with the within-run speed ratios below; 1× means equal throughput. Ratios reduce machine variation but do not replace paired old/new tests on one machine. Expand raw results for absolute throughput and encoding time/size. The memory-copy measurement is a reference, not a theoretical PNG ceiling. Tooltips show the measurement date and CPU. Click a point to open its GitHub Actions run, or its commit when older data has no run record.

Speed ratios divide reference time by ptpng time: above 1× is faster. File-size ratios divide ptpng bytes by reference bytes: below 1× is smaller. The dashed 1× line means equal performance or equal file size. Encoding comparisons include both zlib-ng level 1 and level 6, so speed and compression can be judged together.

Decoder points from e6f083c onward use medians of 12 alternating rounds; earlier points used best-of-12 timings.
